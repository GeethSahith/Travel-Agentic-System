# AI Travel Agent (Multi Agent System)

An advanced, multi agent AI system built with **LangGraph** and **LangChain** that autonomously plans detailed travel itineraries. It uses parallel execution to gather weather forecasts, tourist attractions, luxury hotels, top rated restaurants, and high quality images simultaneously, synthesizing them into a cohesive day by day plan.

## Features

- **Multi Agent Architecture:** Utilizes specialized agents for Orchestration, Weather, Places, Hotels, Restaurants, Images, and Synthesis.
- **Parallel Execution:** Data gathering agents run concurrently, making the pipeline fast.
- **Smart Data Extraction:** Uses a hybrid parsing approach. It prioritizes clean API JSON and falls back to LLM extraction for unstructured organic search snippets.
- **Local LLM:** Powered entirely by a local LLM (Mistral/Llama via Ollama).
- **Image Optimization:** Assigned destination images locally using smart keyword matching to reduce API calls.

## Architecture

The system uses a shared state across all agents in the form of `TripState`.


1. **Orchestrator:** Parses raw user input into a structured query (destination, budget, dates).
2. **Parallel Workers:** 4 agents (Weather, Places, Hotels, Restaurants) query their respective APIs simultaneously.
3. **Images Agent:** Waits for the parallel workers to finish, then fetches photos for the specific entities discovered.
4. **Synthesizer:** Takes all the collected data and uses the LLM to write a readable summary and itinerary.

## Getting Started

1. **Python 3.10+**
2. **Ollama:** Installed and running locally. Pull the Mistral model:
   ```bash
   ollama pull mistral
   ollama serve 
   ```
3. **API Keys:**
   - [Serper api](https://serper.dev/) (For Places, Hotels, Restaurants, Images)
   - [OpenWeatherMap api](https://openweathermap.org/) (For Weather)

### Installation

1. Clone the repository and navigate to the folder.
2. Create and activate a virtual environment:
   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # Mac/Linux:
   source .venv/bin/activate
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Set up environment variables:
   - Copy `.env.example` to `.env`
   - Paste your Serper and OpenWeatherMap API keys inside `.env`

## Usage

Run the CLI application by passing your travel prompt:

```bash
python run.py "Plan a luxury trip to Goa for 5 days"
```

The system will start, execute the parallel graph, and give the travel plan.

## Generated Outputs

When you run the script, it automatically generates two files in the root directory:

### 1. `travel_plan.json`
This is the complete, raw data output of the entire trip. It contains the final structured data in the form of `TripState` schema, including:
- Daily weather forecasts (min/max temps, descriptions)
- Arrays of structured places, hotels, and restaurants (names, ratings, prices, addresses)
- The day by day text itinerary generated by the Synthesizer
- Image URLs assigned to each subject

### 2. `visualize.png`
LangGraph automatically renders a visual diagram of the execution graph during runtime. This image shows the exact nodes and edges of how the agents communicated to fulfill that specific request.
